## What I work on

- **Real-time communication** — audio, video, screen sharing, and data channels with WebRTC.
- **Java and native code** — bringing native media capabilities to Java desktop applications through JNI.
- **Digital teaching** — software for presenting, recording, streaming, and playing back lectures.

## Explore my projects

### [webrtc-java](https://github.com/devopvoid/webrtc-java)

WebRTC for Java desktop applications on **Windows, macOS, and Linux**. A Java API backed by native WebRTC, with prebuilt native libraries and support for audio, video, screen sharing, and data channels.

**Java · C++ · JNI · WebRTC**

[Documentation & getting started](https://jrtc.dev) · [Examples](https://github.com/devopvoid/webrtc-java/tree/main/webrtc-examples) · [Discussions](https://github.com/devopvoid/webrtc-java/discussions)

### [lectureStudio](https://github.com/lectureStudio/lectureStudio)

An open-source toolkit for teaching with PDF slides: present and annotate, record and stream lectures, collect audience feedback, and edit recordings afterward.

**Java · Desktop · Audio & video**

[Website & downloads](https://www.lecturestudio.org) · [Source code](https://github.com/lectureStudio/lectureStudio) · [Discussions](https://github.com/lectureStudio/lectureStudio/discussions)
